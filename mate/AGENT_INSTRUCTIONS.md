## AI Mate Agent Instructions

This file is generated by `docker compose exec -T php vendor/bin/mate discover`. The tooling is a regular dev
dependency of this project (`composer.json`: `symfony/ai-mate`); the binary lives at
`vendor/bin/mate`. You can confirm the available tool surface at any time with
`docker compose exec -T php vendor/bin/mate tools:list`.

AI Mate provides diagnostic tools that report measured facts about the running
application instead of inferences from reading code. Always invoke Mate as
`docker compose exec -T php vendor/bin/mate`; another interpreter reports on a runtime that is not this
application's, and Mate refuses to run under one.

Discover the tools with `docker compose exec -T php vendor/bin/mate tools:list`, inspect a tool's parameters with
`docker compose exec -T php vendor/bin/mate tools:inspect <tool>`, and run one with
`docker compose exec -T php vendor/bin/mate tools:call <tool> --<param>=<value>` (add `--format=json` for
machine-readable output). The sections below describe the installed extensions and
their tools; prefer them over the equivalent raw shell commands when they cover
what you need.

---

### OpenDXP

These tools read the OpenDXP installation you work on. They boot its kernel, so every answer
matches the installed versions, classes and configuration. Load the skill `mate-opendxp-dev` before you
write OpenDXP code. It says when to call which tool and which skill covers the task.

| Tool                       | Use it when                                                                                      |
|----------------------------|--------------------------------------------------------------------------------------------------|
| `opendxp_project`          | Once per session. Core version, bundles with version and enabled state.                          |
| `opendxp_model_schema`     | Before you read or write a data object. Classes, fields, relation types, collections and bricks. |
| `opendxp_site_config`      | Before you use a website setting, a thumbnail, a site or a language.                             |
| `opendxp_documents`        | Before you build a document type or an areabrick. The installed ones with their capabilities.    |
| `opendxp_docs`             | To search docs.opendxp.io. `--channel=next` searches the docs of the development branches.       |
| `opendxp_update_options`   | When the developer asks which updates there are. Load the skill `opendxp-upgrade`.               |
| `opendxp_upgrade_plan`     | After `composer update`. Load the skill `opendxp-upgrade` for the whole update.                  |
